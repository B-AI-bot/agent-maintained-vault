# Verify before assuming

**Rule:** before stating a date, a figure or a status, open its canon or its source and quote it.

**Why:** an agent reported a deadline from last month's journal; the canon had moved it.

**How to apply:** volatile fact → `wiki/canon/` of the right vault. No canon → say it is unverified.
